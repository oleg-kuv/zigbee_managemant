# Порядок работы
Для для планирования действий ты опираешься на прикрепленные файлы
Периодически проси обновить вышеуказанные файлы.
При каждом запросе предполагай какой файл структуры может пригодиться, запрашивать его контент, если он не представлен в *_content.md или content.md. Не указывать путь к файлу внутри листинга кода. Выводи только измененную часть в виде "было/стало". При этом позволяется выделять с помощью комментирования измененные блоки или отдельные строки.
Например - 
```python
# ИЗМЕНЕНИЕ 1: пояснение
if something:
    print('ok')
# КОНЕЦ ИЗМЕНЕНИЯ 1

print('hello!') # ИЗМЕНЕНИЕ 2: однострочная пометка
```

Выводи файл целиком, если в нем меньше 300 строк. Большие пояснения делать вне кода, отдельным листингом.
Не изменяй стилистику кода. 

# Прочие требования
## Вывод в листингов
- *.md файлы должны обрамляться в 5 ` (в 5 обратных опострофов). Это нужно для того чтобы листинги кода входящие в контент md листинга не ломали сплошность вывода (первый тройной апостроф ломает сплошность вывода).

## Требования к коду
- Не использовать init.py файлы (или оставлять их пустыми)
- Не использовать относительные импорты. Все импорты описывать в начале файла
- Использовать UV и pyproject.toml для управления зависимостями и виртуальными окружениями
- Использовать .env и env.template для конфигурации переменных окружения
- Использовать Docker Compose profiles:
    - production - реальные датчики + kafka-producer (без эмулятора)
    - dev - эмулятор датчиков (без kafka-producer и реальных датчиков)

# Краткое описание проекта
- Система измерения параметров среды на Zigbee
- Архитектура: Docker-compose, Kafka, Django (ядро), Postgres/TimescaleDB, Grafana
- Единая кодовая база, два инстанса: data-consumer (Celery) и admin-panel (Django)
- Zigbee2MQTT как софт для координатора
- Устройства делятся на: управляемые (актуаторы) и неуправляемые (датчики)
- Основные сущности: PhysicalQuantity, ZigbeeDevice, SensorType, SensorCorrection, DeviceCommand, Automation
- Управляющие команды отправляются напрямую в MQTT (минуя Kafka)
- Координатор: Sonoff ZBDongle-P (Zigbee 3.0 USB)
- Датчики: noname температурные датчики (Zigbee 3.0, IEEE 802.15.4)
